# i3

![i3](https://i3wm.org/img/logo.svg)

[官方文档（英文）](https://i3wm.org/docs/)

配置文件：默认`/etc/i3`，可复制`/etc/i3/config`到`~/.i3/`或`~/.config/i3/`

## 概述

i3是一个平铺窗口管理器，采用BSD许可证发布，采用X11显示协议，主要面向Linux高级用户和开发者，简单高效。

![i3wm](https://i3wm.org/screenshots/i3-9.bigthumb.png)

## 安装

- Debian系: `sudo apt install i3-wm`
- 红帽系：`sudo dnf install i3-wm`
- Arch系: `sudo pacman -S i3-wm`

## 使用(默认快捷键)

![i3wm](https://i3wm.org/docs/keyboard-layer1.png)

![i3wm](https://i3wm.org/docs/keyboard-layer2.png)

**mod键默认为alt键**

- mod+Enter 打开终端
- mod+j/k/l/; 选择聚焦的窗口
- mod+f 全屏窗口
- mod+Shift+q 关闭窗口
- mod+Shift+e 退出i3
- mod+Shift+Space 漂浮窗口

## 配置

**配置文件默认在/etc/i3，可复制/etc/i3/config到~/.i3/或~/.config/i3/**

因为i3官方文档写的较好，所以建议您阅读[官方文档](https://i3wm.org/docs/)。
