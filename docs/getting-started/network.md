# 网络问题专题

众所周知，在中国大陆网络环境下，访问部分技术类网站极其困难。因而设立本专题来解决部分问题。

## 善用镜像源

镜像源不只是Linux的专有工具，在Python、安卓开发上也能够发挥作用。如果某个部件在国内下载缓慢，试试找找镜像源。

## Github加速

- https://gh-proxy.com/ （仅加速文件下载与仓库克隆，不加速用户界面）
- [Watt Toolkit](https://steampp.net/)

## Docker/Podman加速

- https://1ms.run/
- https://xuanyuan.cloud/free
- [南京大学镜像站 (GHCR、GCR等)](https://doc.nju.edu.cn/books/e1654/page/ghcr)

## Steam加速

- 国内各大加速器
- [Watt Toolkit](https://steampp.net/)
- [Steamcommunity 302](https://www.dogfight360.com/blog/)（跳转到Dogfight360博客，下滑查找即可）

## 全局加速

???+ note "没必要"
    使用大多数Linux发行版**并不需要**以下工具辅助，不到万不得已我们**不建议**您使用以下工具。

本节提供一些工具用于在**国内**代理网络，如访问校园网、家庭网等。

**请依照中华人民共和国法律法规使用以下工具。**

- [FlClash](https://github.com/chen08209/FlClash)
- [Clash Verge Rev](https://github.com/Clash-Verge-rev/clash-verge-rev)
- [v2rayN](https://github.com/2dust/v2rayN)
- [Cloudflare Zero Trust](https://www.cloudflare-cn.com/zero-trust/)
